# Библиотека деталей

Склад всех кусочков, которые когда-либо выплюнул `asset_extract` — и тех, что
ушли в атлас, и тех, что были отброшены. Смысл простой: недостающая деталь
часто уже нарезана у прошлого устройства, и тратить генерацию Flow не нужно.

## Что где

```
использованные/*.png        детали, ушедшие в собранные ассеты
неиспользованные/*.png      всё остальное — нарезано и лежит без дела
index.json                  реестр: sha1 -> устройство, размер, откуда взято, used, id, type
_контактка_использованные_NN.png     листы для глаз, по 96 деталей на страницу
_контактка_неиспользованные_NN.png
library.py                  скрипт склада
```

Деления по устройствам нет: всё лежит одной кучей, чтобы листать разом.
Откуда деталь — видно по имени файла, оно начинается с устройства:
`discman_part_003_2b1f2fe1.png`. Хвост — первые 8 знаков sha1, он же ключ
дедупликации: повторная нарезка той же картинки склад не раздувает, у записи
лишь копится список источников (`origins`).

На контактке подпись зелёная у использованных, серая у свободных.

## Ведётся само

Хук `PostToolUse` в `.claude/settings.json`:

- после `asset_extract` — втягивает всю папку нарезки в `неиспользованные/`;
- после `asset_pack` — переносит ушедшие в атлас в `использованные/`, пишет им
  `id` и `type`, перерисовывает обе контактки.

Руками копировать ничего не надо.

## Команды

```bash
py "Библиотека деталей/library.py" stats              # что лежит на складе
py "Библиотека деталей/library.py" scan               # обойти work/ и assets/ заново
py "Библиотека деталей/library.py" rebuild            # сбросить пометки и разложить заново
py "Библиотека деталей/library.py" ingest <dir>       # втянуть одну папку нарезки
py "Библиотека деталей/library.py" sheet              # перерисовать контактки
py "Библиотека деталей/library.py" mark <device.json> # пометить детали готового ассета
```

`scan` безопасен: повторный запуск ничего не дублирует. `rebuild` нужен, если
пометки разъехались — например деталь вынули из ассета вручную.

## Пометка «использована» задним числом

У собранного `device.json` имён исходных файлов нет, поэтому `mark` сопоставляет
детали по `frame.w/h` — они равны натуральному размеру нарезанного PNG. Для
новых сборок пометка точная: её ставит хук по путям из вызова `asset_pack`.
