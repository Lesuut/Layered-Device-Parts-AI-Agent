# Flow Generator

Автоматизация Google Flow: промт → генерация → скачивание 4 картинок в 2K.
Работает **в уже открытом Chrome** (подключение по CDP), логин Google — твой.

Два способа использования: **CLI** (`RUN_TEST.bat`) и **MCP-сервер** для Claude Code.

## Состав

```
install.bat              установка: зависимости + MCP + скилл
RUN_TEST.bat             ручной запуск с вводом промта
start_chrome_debug.bat   поднять отладочный Chrome
run.py                   пусковик: Chrome, проверки, интерактив
flow_gen.py              вся логика работы с Flow
mcp_server.py            MCP-сервер (4 инструмента)
skills/flow-image-gen/   скилл для Claude Code
mcp-config-example.json  конфиг, если ставить руками
```

## Установка как MCP (для Claude Code)

Двойной клик по **`install.bat`** — поставит зависимости, скопирует скилл в
`~/.claude/skills/flow-image-gen` и зарегистрирует сервер командой
`claude mcp add flow-images --scope user`.

Дальше: один раз запустить `RUN_TEST.bat`, войти в Google, открыть проект Flow.
Перезапустить Claude Code, проверить `/mcp`.

Инструменты сервера:

| Инструмент | Что делает |
|---|---|
| `flow_check` | готовность: порт отладки, вкладка Flow, логин |
| `flow_setup` | поднять отладочный Chrome |
| `flow_generate` | промт (+ референсы) → генерация → **ждёт все 4** → качает 2K, отдаёт пути |
| `flow_paste_reference` | только вставить референс в композер, без генерации |
| `flow_list_files` | показать нагенерированные партии |

`flow_generate` блокирующий: возвращается только когда все файлы на диске
(90–180 с на 4 картинки). В ответе JSON с `ok`, `downloaded`, `folder` и списком
`images` — по каждой картинке `path`, `width`, `height`, `bytes`, `upscaled_2k`.

## Референсы (image-to-image)

Картинку можно отдать как образец — она вставляется в композер Flow ровно так,
как это делает человек по Ctrl+V, скрипт **дожидается её загрузки на сайт**
и только потом жмёт «Создать».

```bash
python flow_gen.py --prompt "same device, exploded view" --ref C:\refs\phone.jpg
python flow_gen.py --prompt "..." --ref a.png --ref b.png     # несколько
python run.py --prompt "..." --ref C:\refs\phone.jpg
```

Из Claude Code — параметр `reference_images` у `flow_generate`: список
абсолютных путей, `data:`-URI или http(s)-ссылок.

Способы вставки перебираются по порядку (`--ref-method auto`):

| Метод | Как работает |
|---|---|
| `paste` | синтетический `ClipboardEvent('paste')` с файлом — без буфера ОС, быстрее всего |
| `clipboard` | картинка кладётся в буфер Windows (PNG+Bitmap) и шлётся настоящий Ctrl+V через CDP `Input.dispatchKeyEvent` с `commands:["paste"]` |
| `drop` | синтетический drag&drop файла в композер |
| `upload` | файл подставляется прямо в `input[type=file]` |

Загрузка считается завершённой, когда появилась новая миниатюра, она
отрисована (`naturalWidth > 0`), спиннеров на странице нет и набор миниатюр
не менялся 3 опроса подряд. Если вставить не вышло — **генерация не
запускается** (квота цела), в ответе `error: reference_upload_failed`.
Форсировать генерацию без референса: `--ref-optional`.

## Установка

```bash
pip install -r requirements.txt
```

Браузер качать не надо (`playwright install` не нужен) — скрипт цепляется
к твоему Chrome, а не поднимает свой.

## Запуск

Двойной клик по **`RUN_TEST.bat`** — окно не закрывается, все ошибки видны.
Он проверит Python и playwright (доставит при нужде), сам поднимет Chrome
с портом отладки, покажет вкладки, спросит промт, скачает картинки
и откроет папку с результатом.

**Обычный Chrome закрывать НЕ нужно** — автоматизация работает в отдельном
процессе с профилем `%LOCALAPPDATA%\ChromeDebugProfile`.
В первый раз в этом окне надо войти в Google и открыть свой проект Flow —
дальше сессия сохраняется.

```bash
python run.py                       # интерактивно
python run.py --prompt "текст"
python run.py --setup-only          # только поднять Chrome и залогиниться
```

## Запуск вручную (низкий уровень)

1. `python run.py --setup-only` (или `start_chrome_debug.bat`).
2. Открыть в этом Chrome свой проект Flow.
3. Запустить скрипт:

```bash
python flow_gen.py --prompt "explode view of Nokia 3310, technical illustration"
python flow_gen.py --prompt "..." --out "C:\images" --count 4
python flow_gen.py --list-tabs            # проверить подключение
python flow_gen.py --prompts-file prompts.txt   # пачка промтов
```

Картинки ложатся в `output/<дата_время>_<начало_промта>/img_01_2k.jpeg ...`

## Про 2K

По умолчанию качается **2K с апскейлом** — не прямой `src` из галереи (тот даёт
1200×896), а штатный путь Flow: карточка → `⋮` → «Скачать» → «2K. Увеличенное
разрешение». Результат — 2400×1792, ~2–4 МБ. Если меню почему-то не открылось,
скрипт откатывается на прямое скачивание 1K, чтобы не потерять картинку
(в логе будет строка «откатываюсь на прямое скачивание из src»).

4K требует смены тарифного плана — Flow сам покажет заглушку.

## Ключи

| Ключ | Смысл |
|---|---|
| `--prompt` | текст промта |
| `--prompts-file` | файл с промтами, разделитель — строка `---` |
| `--url` | URL проекта Flow, если вкладка не открыта |
| `--out` | папка вывода (по умолчанию `output`) |
| `--count` | сколько картинок ждать (по умолчанию 4, `0` = все новые) |
| `--cdp` | порт или endpoint (по умолчанию перебор 9222/9223/9224) |
| `--gen-timeout` | сколько ждать генерацию, сек (по умолчанию 600) |
| `--min-side` | мин. сторона картинки в px, отсекает иконки (256) |
| `--quality` | `2k` (по умолчанию, 2400×1792 с апскейлом), `1k`, `4k` (нужен тариф), `src` — быстрый прямой забор 1200×896 без меню |
| `--ui-timeout` | ожидание апскейла и загрузки, сек (180) |
| `--ref` | картинка-референс: путь, `data:`-URI или ссылка; можно несколько раз |
| `--ref-method` | `auto` (по умолчанию), `paste`, `clipboard`, `drop`, `upload` |
| `--ref-timeout` | ожидание загрузки референса, сек (90) |
| `--ref-thumb-max` | макс. сторона миниатюры референса, px (220) |
| `--ref-optional` | генерировать, даже если референс не вставился |
| `--dry-run` | проверить селекторы без траты генерации |
| `--list-tabs` | показать вкладки и выйти |

## Если что-то не так

- **«Не нашёл Chrome с открытым портом»** — Chrome запущен без флага.
  Закрыть его полностью и запустить через `.bat`.
- **Chrome 136+** не даёт отладку на стандартном профиле — поэтому `.bat`
  использует отдельную папку `%LOCALAPPDATA%\ChromeDebugProfile`.
- **Порт 9222 занят другим приложением** (например Lens Studio — оно тоже
  отвечает на `/json/version`) — скрипт это распознаёт по строке `Browser`
  и молча уходит на 9223/9224. В логе: «Пропускаю ...: это не Chrome».
- **Не нашёл поле ввода / кнопку** — Flow поменял вёрстку.
  Правятся списки `PROMPT_SELECTORS` и `SUBMIT_SELECTORS` вверху `flow_gen.py`.
- **Референс «не догрузился»**, хотя миниатюра видна — Flow рисует чип крупнее
  220 px. Поднять `--ref-thumb-max` (например 400).
- **Референс не вставляется ни одним методом** — проверь отдельно
  `python flow_gen.py --prompt "x" --ref f.png --ref-method clipboard`,
  окно Chrome при этом должно быть на переднем плане.
- **Скачались превью вместо оригиналов** — поднять `--min-side` (например 512).
